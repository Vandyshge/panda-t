# PANDA-T Density Profile Viewer

Interactive web viewer for analytical density profiles in an equilateral triangular pore for the special case of a contact angle of **180°**.

The viewer includes four morphology types:

- Wall droplet (`droplet_w1`)
- Free filament (`filament_w0`)
- Three-wall filament (`filament_w3`)
- Three-wall capsule (`capsule_w3`)

The parameters \(\phi\), \(\delta\), and \(l\) can be varied interactively. Valid existence regions for each morphology are highlighted directly on the sliders.

## Usage

Open `index.html` in any modern web browser.

## PANDA-T

This viewer is intended as an interactive supplement for the PANDA-T model for confined liquid morphologies in triangular nanopores.
